# Состав и описание зависимостей проекта

## 1. Веб-фреймворк и его окружение

Пакеты формируют основу для приложения на Python.

- **Flask (3.1.2)** — микрофреймворк для создания веб-приложений. Версия 3.1.2 — это исправляющий релиз, который устраняет ошибки, не меняя поведения и не внося критических изменений.

- **Werkzeug (3.1.3)** — библиотека утилит для WSGI-приложений, на которой основан Flask. Предоставляет мощный отладчик, объекты запросов и ответов, а также утилиты для работы с HTTP.

- **Jinja2 (3.1.6)** — быстрый и выразительный шаблонизатор, используемый во Flask для генерации HTML-страниц.

- **MarkupSafe (3.0.3)** — библиотека для безопасной работы со строками в HTML/XML. Экранирует специальные символы, что помогает предотвратить XSS-атаки при выводе пользовательских данных.

- **itsdangerous (2.2.0)** — набор утилит для криптографической подписи данных, которые передаются в ненадёжную среду (например, в куки или URL), чтобы обеспечить их целостность.

- **blinker (1.9.0)** — библиотека для реализации системы сигналов и событий. Позволяет различным частям приложения подписываться на события и реагировать на них, не создавая сильных связей между компонентами.

- **click (8.3.0)** — пакет для создания удобных интерфейсов командной строки (CLI) с минимальным количеством кода.

- **colorama (0.4.6)** — обеспечивает кросс-платформенную поддержку цветного текста в терминале, что особенно актуально для Windows.

## 2. Работа с базами данных

Библиотеки отвечают за взаимодействие с базами данных.

- **Flask-SQLAlchemy (3.1.1)** — расширение для Flask, которое упрощает интеграцию с SQLAlchemy, предоставляя полезные значения по умолчанию и помощники для типовых задач.

- **SQLAlchemy (2.0.43)** — мощный и гибкий инструмент для работы с базами данных, включающий в себя ORM (Object Relational Mapper) и SQL-выражения.

- **psycopg2-binary (2.9.10)** — адаптер для работы с базой данных PostgreSQL из Python. Версия binary включает предварительно скомпилированные бинарные файлы, что упрощает установку.

- **greenlet (3.2.4)** — библиотека, предоставляющая легковесные корутины (микро-потоки) для параллельного программирования в одном процессе. Используется некоторыми асинхронными библиотеками и SQLAlchemy для обеспечения неблокирующего ввода-вывода.

## 3. Обработка форм и валидация

Пакеты для работы с веб-формами.

- **Flask-WTF (1.2.2)** — расширение для Flask, которое упрощает интеграцию с библиотекой WTForms и добавляет встроенную защиту от CSRF-атак.

- **WTForms (3.2.1)** — гибкая библиотека для валидации и рендеринга веб-форм, которая может работать с любым фреймворком и шаблонизатором.

- **email-validator (2.3.0)** — библиотека для проверки синтаксиса и, опционально, реальной возможности доставки email-адресов.

## 4. Обработка документов и форматов данных

Инструменты для работы с различными файлами.

- **lxml (6.0.2)** — высокопроизводительная и многофункциональная библиотека для обработки XML и HTML, основанная на библиотеках libxml2 и libxslt.

- **openpyxl (3.1.5)** — библиотека для чтения и записи файлов Excel формата `.xlsx`/`.xlsm`.

- **python-docx (1.2.0)** — библиотека для создания и обновления файлов Microsoft Word (`.docx`).

- **et_xmlfile (2.0.0)** — вспомогательная библиотека для openpyxl, предназначенная для создания больших XML-файлов с низким потреблением памяти.

## 5. Утилиты и сетевые протоколы

Вспомогательные библиотеки общего назначения.

- **gunicorn (23.0.0)** — HTTP WSGI-сервер для UNIX-подобных систем. Используется для запуска Python-веб-приложений (например, на Flask) в production-среде.

- **packaging (25.0)** — предоставляет основные утилиты для работы с версиями пакетов, спецификаторами и зависимостями согласно стандартам Python Packaging.

- **typing_extensions (4.15.0)** — бэкпорт новых функций системы типов Python для их использования на более старых версиях интерпретатора, а также для экспериментов с новыми PEP до их включения в стандартную библиотеку.

- **dnspython (2.8.0)** — набор инструментов для работы с DNS-протоколом из Python. Поддерживает запросы, зонные трансферы и динамические обновления.

- **idna (3.10)** — библиотека для поддержки интернационализированных доменных имён (IDNA), позволяющая использовать домены с символами Unicode в соответствии со стандартом RFC 5891.
